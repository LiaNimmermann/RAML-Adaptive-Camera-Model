# Adaptive Camera Model for Computer Vision - Extending Datasets for Task-Aware Camera Parameter Optimization
Task-aware camera control can improve downstream vision performance, but learning suitable
policies requires data covering many camera configurations, which are costly to capture and
difÏcult to reproduce realistically through image recapture. We introduce a physically grounded
simulating pipeline that models exposure-dependent effects such as clipping, sensor noise,
and quantization from HDR images, opening the opportunity to extend existing datasets with
HDR data, such as Cityscapes or PASCALRAW, for camera parameter optimization.


This is still a work in progress. We were accepted to present this work as an extended abstract in the WiCV workshop at ECCV 2026. Refer to the Poster for more information.
